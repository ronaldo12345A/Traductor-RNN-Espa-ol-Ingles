Traductor RNN Español-Inglés

Sistema de Traducción Automática con Redes Neuronales Recurrentes

📊 Dataset

Utilizamos un dataset bilingüe de alta calidad con miles de pares de oraciones español-inglés para entrenar nuestro modelo.

  • Dataset de Kaggle: English-Spanish Translation
  • Dataset complementario creado específicamente
  • Más de 1,000 frases de alta calidad
  • Traducciones validadas y precisas

🤖 Arquitectura RNN

Nuestro modelo utiliza una arquitectura RNN avanzada con LSTM bidireccional para capturar dependencias temporales en el lenguaje.

  • Embedding Layer para representación de palabras
  • LSTM Bidireccional para contexto completo
  • Mecanismo de atención implícito
  • Decoder LSTM para generación de texto

⚙️ Preprocesamiento

Los datos pasan por un riguroso proceso de limpieza y preparación antes del entrenamiento.

  • Tokenización de texto en español e inglés
  • Limpieza de caracteres especiales
  • Normalización a minúsculas
  • Padding de secuencias para longitud uniforme

📈 Métricas de Rendimiento

Nuestro modelo ha demostrado un excelente rendimiento en las pruebas de traducción.
